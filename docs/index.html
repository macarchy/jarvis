Jarvis

le poisson de Babel

A bilingual voice assistant that lives on one laptop, with Claude as its brain, the shell as its hands, and a pixel-art Babel fish as its face. He answers in the language you spoke, and he remembers yesterday.

cinq portes

La machine

Eight states, nine events, drivable. Press the events and watch the illegal ones be refused, with the reason. Thirty seconds here beats reading the architecture.

Vie privée

What leaves your machine. Audio never does. The transcript goes to Anthropic. The screen and the clipboard only when you ask, in that exchange. With the source lines that prove it.

Dépannage

When something is red. One entry per line doctor can print, in the order it prints them — and the things it cannot see.

Le poisson

Twelve sheets, 256 fish. The sprite engine — every gesture is built from parts and proved on all 256 configurations before it is accepted.

L’assembler

Four bodies, four eyes, four crests, four tails. Roll your own fish, then write the five settings into SOUL.md.
l'installer 
git clone https://github.com/macarchy/jarvis.git ~/Work/jarvis
cd ~/Work/jarvis
./bootstrap.sh      # Piper, its voices, the Whisper model, the wake venv
./install.sh        # the CLI, the mascot plugin, the user units
omarchy-jarvis doctor

The voice loop is portable — Linux, PipeWire, voxtype, Claude Code. The hands need Omarchy and Hyprland, and the body needs Quickshell; both fail softly, so on a plain Linux box he still listens, thinks and speaks. The full honesty is in the README (en français).
