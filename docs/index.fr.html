Jarvis

le poisson de Babel

Un assistant vocal qui tient dans un fichier bash. Claude comme cerveau, le shell comme mains, et un poisson de Babel en pixel art comme visage. Il répond dans la langue que tu as parlée, et il se souvient d’hier.

cinq portes

La machine

Huit états, neuf événements, pilotable. Appuie sur les événements et regarde les coups illégaux être refusés, avec leur raison. Trente secondes ici valent mieux que lire l’architecture.

Vie privée

Ce qui quitte ta machine. L’audio, jamais. Le transcript part chez Anthropic. L’écran et le presse-papier seulement quand tu le demandes, dans l’échange en cours. Avec les lignes de code qui le prouvent.

Dépannage

Quand quelque chose est rouge. Une entrée par ligne que doctor peut afficher, dans l’ordre où il les affiche — et ce qu’il ne peut pas voir.

Le poisson

Douze planches, 256 poissons. Le moteur de sprites — chaque geste est assemblé depuis des pièces et prouvé sur les 256 configurations avant d’être accepté.

L’assembler

Quatre corps, quatre yeux, quatre crinières, quatre queues. Tire ton propre poisson, puis écris les cinq réglages dans SOUL.md.
l’installer 
git clone https://github.com/macarchy/jarvis.git ~/Work/jarvis
cd ~/Work/jarvis
./bootstrap.sh      # Piper, ses voix, le modèle Whisper, le venv du réveil
./install.sh        # le lien de commande, le greffon, les unités utilisateur
omarchy-jarvis doctor

La boucle vocale est portable — Linux, PipeWire, voxtype, Claude Code. Les mains exigent Omarchy et Hyprland, et le corps Quickshell ; les deux tombent en douceur, donc sur un Linux ordinaire il écoute, réfléchit et parle toujours. Toute l’honnêteté est dans le README (in English).
