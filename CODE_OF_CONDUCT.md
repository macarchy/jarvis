# Code of conduct

This project adopts the [Contributor Covenant, version 2.1][cc], in full. The
canonical text lives at that link rather than being copied here, so it cannot
drift out of date in a file nobody re-reads.

The short version, in this project's own words: **be someone people want to
debug with.** Assume the other person read the code and reached a different
conclusion for a reason. Disagree about the work, not the person. If you are
correcting someone, correct the thing and move on.

Jarvis speaks French and English, and so do the people around it. Neither is
the "real" language here, and imperfect English in an issue is not a defect —
the same goes for imperfect French.

## Reporting

If someone's behaviour makes this project worse to be part of, tell the
maintainer privately rather than arguing in a thread. Use GitHub's
[private vulnerability & abuse reporting][report] on this repository, or open a
direct conversation with the maintainer.

Reports are read by one person — this is a small project, not an institution
with a committee. You will get an answer, and what you write stays between us
unless you say otherwise.

[report]: https://github.com/macarchy/jarvis/security/advisories/new
